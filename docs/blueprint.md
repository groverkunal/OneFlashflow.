# **App Name**: FlashFlow

## Core Features:

- File Upload: Option to upload files (txt, pdf, docx).
- Text Input: Option to paste text directly into the app.
- Agent Powered Content Parsing: AI-powered content parsing: different AI "tool" profiles extract and classify info to generate flashcards, for facts, figures, historical contexts, news, definitions, examples, analogies, applications, or implications. Users can choose which profiles to apply.
- Flashcard Display: Display information in a flashcard format.
- Navigation: Enable scrolling or swipe navigation between flashcards.

## Style Guidelines:

- Primary color: Muted violet (#9D69A3) to bring a sense of calm, focus and attention to detail.
- Background color: Light grey-violet (#F4F0F5) offers soft contrast, enabling comfortable long reading times.
- Accent color: Dusty rose (#C1858E) provides a complementary accent that won’t distract.
- Headline font: 'Belleza' sans-serif, to lend some visual interest
- Body font: 'Alegreya' serif, for longer sections of text
- Simple, minimalist icons to represent different agent categories (e.g., a calculator for figures, a calendar for historical references).
- Clean and intuitive layout with a focus on readability. Flashcards should take center stage with minimal distractions.
- Subtle transitions between flashcards. A progress bar at the top indicating the flashcard position.
